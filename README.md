# Персональний менеджер завдань

Простой консольный менеджер задач на Python. Интерфейс программы — на украинском языке.

## Мета проєкту

Розробити консольну програму мовою Python для створення, зберігання, пошуку, редагування, сортування та аналізу списку особистих завдань. Проєкт передбачає практичне застосування основних конструкцій мови Python: змінних, рядкових і числових величин, списків, умовних операторів, циклів та функцій.
